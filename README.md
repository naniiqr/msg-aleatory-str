# Caravaning Vilamacolum – plantilles Elementor

Idioma del web: **català**. Disseny segons `caravaning_vilamacolum.pdf` (Inici, Parking, Serveis).

Pàgines a `elementor/`: `inici`, `parking`, `serveis`, `installacions`, `sobre-nosaltres`, `contacte`.
Importació: Elementor > Plantilles > Plantilles desades > Importa, i després "Insereix" a cada pàgina.
Regenerar: `python3 tools/build_pages.py`.

Pendents: capçalera/peu (Theme Builder), pujar la resta d'imatges (ara hi ha placeholders) i revisar
els textos de "Sobre nosaltres" (marcats entre claudàtors).
